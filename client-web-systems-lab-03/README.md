# Лабораторна робота №3. Компоненти, шаблони, директиви (Vue 3)

## Запуск

```bash
npm install
npm run dev        # dev-сервер
npm run lint       # ESLint
npm run build      # перевірка типів + збірка
```

Фото користувачів: `public/users/user-1.jpg` ... `user-10.jpg`.
Скріншоти tutorial: `public/tutorial/step-N.png`.

## Контрольні питання

1. **Компонент** — незалежний багаторазовий блок UI зі своїм шаблоном, логікою і стилями. Застосунок складається з дерева компонентів.
2. **SFC** (`.vue`) — файл, що об'єднує розмітку, логіку і стилі компонента. Секції: `<template>`, `<script>` / `<script setup>`, `<style>`.
3. **Шаблон** — HTML-розмітка компонента, де можна використовувати інтерполяцію `{{ }}`, директиви, JS-вирази, прив'язки й обробники подій.
4. Шаблон Vue — це HTML-синтаксис із декларативним зв'язком із даними компонента: він компілюється в render-функцію і автоматично оновлюється при зміні стану.
5. **Директиви** — спеціальні атрибути з префіксом `v-`, які додають шаблону реактивну поведінку. Синтаксис: `v-name:argument.modifier="expression"`.
6. **`v-bind`** динамічно прив'язує атрибут або prop до виразу, наприклад `<img v-bind:src="user.picture" />`.
7. `:src="..."` — скорочений запис `v-bind:src="..."`, різниці у поведінці немає.
8. **`v-if`** рендерить елемент за умовою: при `false` елемент видаляється з DOM. `v-else-if` і `v-else` утворюють ланцюжок умов. `v-show` лише перемикає CSS `display`, елемент залишається в DOM; `v-if` дорожчий при перемиканні, `v-show` — при початковому рендері.
9. **`v-for`** виводить список із масиву чи об'єкта. `:key` має бути унікальним і стабільним (наприклад, `id`, не індекс), щоб Vue коректно перевикористовував і переставляв елементи.
10. **Реактивність** — Vue відстежує використання реактивного стану (`ref`, `reactive`) і при його зміні автоматично оновлює лише ті частини DOM, що від нього залежать.
